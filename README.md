# Projeto: Pipeline de Dados de Vendas na Nuvem (Microsoft Azure + Power BI)

### 📌 Sobre o Projeto
Este projeto simula o cenário real de uma empresa de varejo que migrou seus dados locais para a nuvem para ganhar escala, segurança e relatórios automáticos. Eu criei um fluxo contínuo onde os dados brutos de vendas passam por um banco de dados em nuvem e alimentam um painel interativo de tomada de decisão.

### 🛠️ Tecnologias e Ferramentas Utilizadas
* **Microsoft Azure (Blob Storage):** Armazenamento em nuvem do arquivo bruto de vendas.
* **Azure SQL Database:** Banco de dados relacional na nuvem para organização das tabelas.
* **SQL:** Criação de tabelas e consultas estruturadas.
* **Microsoft Power BI:** Conexão direta com a nuvem e criação de dashboards gerenciais.
* **Excel:** Estruturação inicial da base de dados fictícia.

### 📐 Arquitetura do Fluxo de Dados
O projeto segue o seguinte fluxo de engenharia e análise:
`Excel (Dados Brutos) ➔ Azure Blob Storage ➔ Azure SQL Database ➔ Power BI Desktop`

### 📊 Principais Indicadores Analisados (KPIs)
* **Faturamento Total:** Valor bruto acumulado no período.
* **Volume de Vendas:** Quantidade total de produtos vendidos.
* **Desempenho por Canal:** Comparativo de vendas entre Site, WhatsApp e Loja Física.
* **Produtos Mais Vendidos:** Ranking por faturamento e quantidade.

### 🚀 O que eu aprendi desenvolvendo este projeto
* Como configurar recursos fundamentais de armazenamento na nuvem Microsoft Azure.
* Integração de ferramentas de Business Intelligence diretamente com fontes cloud.
* Aplicação prática dos conceitos de administração de banco de dados e relacionamentos.
